# Django E-Commerce Website

## Description
A full stack E-Commerce web application for bike riding gear and accessories.

## Tech Stack
- Django
- HTML
- CSS
- MySQL

## Features
- User registration & login
- Product listing
- Order placement
- Admin Product management

## How to Run
1. Install Python
2. Install Django
3. Configure MySQL in settings.py
4. Run migrations
5. Start server:
   python manage.py runserver
